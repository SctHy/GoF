# 界面行为

当前只有用户端页面：登录/注册、Feed、上传、个人资料、公开用户页和消息中心。没有搜索、分享、审核或运营页面，界面不展示没有后端实现的入口。

- 桌面侧栏切换最新、推荐、关注和热门 Feed；窄屏使用可关闭的导航抽屉。
- Feed 播放器支持上下切换、播放/暂停和静音。进度与首帧、卡顿统计来自真实媒体事件。
- 点赞、收藏、关注需要登录。评论在抽屉中打开，加载失败保留当前视频和用户输入。
- 分页失败停止自动追加，游标过期要求显式刷新，不自动跳回首页。
- 上传选择视频与封面，上传完成后才允许发布。个人作品页支持删除自己的视频。
- 消息区分未读状态，支持标记已读；互动者来自 API 的 actor 字段，不从通知文本猜测用户身份。
- 头像缺失用首字占位，封面缺失使用本地 SVG；不请求外部演示头像。
- 键盘焦点位于输入框、弹窗或输入法组合输入中时，不响应 Feed 切换快捷键。弹窗负责焦点限制与关闭后的恢复。

组件采用 shadcn Base UI，应用布局与播放器交互在业务组件中实现。代码分工与测试入口见[前端开发](frontend-development.md)。
